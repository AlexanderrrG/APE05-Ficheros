# 📝 Práctica APE 05 - Creación, Lectura y Escritura de Ficheros

Este repositorio contiene el desarrollo práctico de la guía APE 05 para la asignatura de Algoritmos y Lógica de Programación. El objetivo principal de estos ejercicios es aplicar los conceptos de Programación Orientada a Objetos (POO) para manipular archivos de texto plano (.txt) usando los lenguajes Java ☕ y C++ ⚙️.

## 🗂️ ¿Qué hay en este repositorio?
He organizado los archivos según la estructura solicitada en la guía para mantener el orden del proyecto:

* 📂 **`/src`**: Aquí se encuentra todo el código fuente de los ejercicios resueltos.
* 📸 **`/capturas`**: Contiene las evidencias de los programas ejecutándose correctamente, además de capturas de los métodos y clases creadas.
* 📄 **`/archivos`**: Archivos `.txt` generados por los programas durante las pruebas de guardado y lectura de datos.
* 📑 **`informe.pdf`**: El documento formal con el análisis, diagramas, algoritmos y conclusiones de la práctica.

## 🚀 Ejercicios Desarrollados
El proyecto incluye la resolución de los 10 problemas planteados, entre los que destacan:
1. 🧑‍🎓 Registro y lectura de estudiantes.
2. 📦 Sistema básico de inventario.
3. 📞 Agenda telefónica.
4. 🏧 Simulador de un cajero automático.
5. 📚 Biblioteca virtual interactiva.

✅ Todos los ejercicios incluyen validación de datos por consola, un menú interactivo y aseguran la persistencia de los datos en disco duro.
