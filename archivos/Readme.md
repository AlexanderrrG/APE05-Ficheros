# 📄 Archivos de Texto (Persistencia de Datos)

Esta carpeta está destinada a guardar los documentos de texto plano (`.txt`) que los programas de C++ y Java generan automáticamente durante su ejecución.

Estos archivos, como `cajero.txt`, `biblioteca.txt` o `estudiantes.txt`, sirven para demostrar que la escritura, lectura y actualización de ficheros (persistencia de datos en el disco duro) funciona correctamente.
